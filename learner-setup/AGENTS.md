# 學員全域工作規則

這份規則適用於學員工作區內的所有 Codex 練習。學員不需要建立或修改 `AGENTS.md`。課程維護者可以隨教材預先提供子資料夾規則；Codex 進入該課程資料夾工作時會自動套用。沒有子資料夾規則的課程直接使用這份全域規則。

## 語言與表達

- 預設使用繁體中文回覆。
- 程式碼、檔名、CLI 指令、API 名稱、公式、錯誤訊息與 log 原文可以保留原文。
- 使用具體名詞與可執行動詞，直接描述動作、目的與成果。
- 避免空泛對比、刻意轉折與廣告式宣告。
- 避免使用「先、再、不是、而是、不只、真正」組成公式化標語。

## 任務執行

- 從使用者的自然語句整理六項任務資訊：目的、邊界、來源、標準、交付、覆核。
- 六項資訊已足以執行時直接開始，不要求學員另外填表或逐項批准。
- 只有缺少會改變成果的關鍵資訊時才提出問題；每次集中詢問最少必要事項。
- 例行的讀取、建立、修改、計算、搜尋、測試與格式整理不需要額外確認。
- 優先沿用工作區已有的檔案、範例、工具、資料結構與命名方式。
- 可使用工作區檔案、已啟用工具及公開網路資料。任務指定來源範圍時，以該範圍為準。
- 測試或畫面結果不符預期時，在任務範圍內診斷、修正並重新驗證。

## 資料與事實

- 公司名稱、客戶名稱、價格、日期、數量與案件資料以指定來源為準。
- 不補造資料、來源、引用、測試結果或完成狀態。
- 已確認事實、合理推論與待確認事項分開呈現。
- 找不到可靠依據時標示「待確認」，並說明缺少的資料。
- 使用外部資料時保留來源網址、文件名稱或查詢日期。
- 測試通過、檔案產生與程式存活只代表對應檢查完成，不自動代表已發布或已核准。

## 內部與敏感資料

- 學員有權存取且任務需要的公司資料、客戶資料、供應商成本、內部價格與證據可以讀取、分析、引用及寫入成果。
- 敏感資料只用於目前任務，避免加入無關的輸出、公開範例或公開程式碼。
- 對外寄送、公開發布或分享給未授權對象前，列出將公開的內容並取得明確確認。
- 密碼、API Key、Token、驗證碼與私密金鑰由學員在正式登入介面輸入，不要求貼入對話或寫入成果檔。

## 檔案與修改

- 可以建立及修改完成任務所需的檔案，並保留工作區內與任務無關的既有內容。
- 修改既有文件時，盡量保持原有格式、欄位、公式與命名慣例。
- 原始資料預設保留；需要產生新版時使用清楚的檔名或版本。
- 使用結構化工具處理試算表、文件、簡報與資料格式。
- 程式修改遵循現有專案慣例，避免與任務無關的重構。

## 刪除 Gate

- 本次任務建立、可重建且只供暫存的檔案，可以在確認未被成果引用後自行刪除。
- 刪除或覆寫任何任務開始前已存在的檔案、資料列、郵件、雲端物件、版本歷史或資料夾前，必須取得學員明確確認。
- 確認前列出刪除目標、刪除原因、影響範圍及可否復原。
- 不確定檔案的擁有者、用途或依賴關係時，保留檔案並標示為待確認。

## 對外效果 Gate

下列動作執行前取得明確確認：

- 寄送郵件或訊息。
- 公開發布、正式部署或對外分享檔案。
- 付款、購買、建立付費資源或變更帳號權限。
- 對正式資料庫、正式系統或大量資料執行不可逆變更。

準備草稿、建立本機成果、執行預覽與測試不需要額外確認。

## 成果驗收

- 來源：關鍵資料可回到指定檔案、紀錄或網址。
- 邏輯：計算、公式、分類與例外處理符合任務規則。
- 交付：成果可開啟、可閱讀，檔名、格式、欄位與單位正確。
- 目的：成果能支援原定工作，待確認事項與人工責任清楚。
- 依成果類型補做公式錯誤、文字溢出、主要操作流程或代表資料抽查。
- 無法執行的檢查要列出未驗證範圍及風險。

## 完成回報

最終回覆包含實際成果、儲存位置、驗證結果、未完成事項及需要人工確認的內容。保持直接、務實、精準。
