# Slide Copy Rules

Customer slides are visual aids for a meeting. They are not the meeting
script. Put the explanation in speaker notes when the deck format supports
notes; otherwise keep it in the private build note. Do not put the explanation
on the slide.

## Visible Copy Budget

- Title: 4–12 Chinese characters where possible.
- Section label: 2–6 characters.
- Diagram node: 2–8 characters.
- Supporting text: one short line, only when a label is not enough.
- Default: no paragraph, no claim rail, no more than three support labels.

Use the empty space for a product image, a process, a before/after view, a
layout, or a number with a unit. Do not fill it with explanatory prose.

## Page Shape

Prefer this order:

1. Short title.
2. One visual: photo, illustration, flow, map, comparison, or architecture.
3. Two to four labels attached to the visual.
4. One small source or confirmation line if necessary.

For process pages, use `A → B → C`. For system pages, use
`資料 → 任務 → 設備`. For improvement pages, use `現況 → 動作 → 結果`.
Keep the labels editable. Do not explain each arrow in a paragraph.

## Short Title Examples

Use the shortest natural phrase that tells the room what to look at:

- `包裝先穩`
- `棧板先定位`
- `通道先量`
- `先看庫存`
- `產品決定乾燥`
- `先做狀態回報`
- `先確認載重`

Avoid topic labels such as `設備選型方向`, `WMS 架構`, `改善主軸`, or
`乾燥設備比較分析`. Avoid slogans and sentences that sound like a report
abstract.

## Word Choice

Use nouns and verbs that can be pointed to on site:
`找料、補料、定位、切片、冷卻、放行、回報、追溯、通道、載重、儲位`.

Use a number only when the source supports it. Otherwise use a short prompt:
`待確認：通道寬度` or `待確認：每日任務數`.

Do not write `提升效率`, `強化管理`, `打造完整方案`, or `提高可視性`
without showing the object or the measurement. Prefer the object itself:
`棧板 ID`, `任務狀態`, `重工件數`, `水活性`, `通道寬度`.

## Remove AI-Sounding Phrases

Delete these openings and endings unless they are part of a direct quotation:

- `本案建議` / `本次規劃` / `我們建議`
- `透過…提升…`
- `有助於…` / `可有效…` / `進一步…`
- `以…為核心` / `以…為主軸` / `建立完整…`
- `打造…` / `實現…` / `全面…` / `全方位…`
- `一站式解決方案` / `智慧化升級` / `數位轉型`

Replace the sentence with the visible action or object:

- `透過系統整合提升管理效率` → `庫存、任務、設備`
- `建立完整的物流改善方案` → `儲位 → 搬運 → 回報`
- `以自動化為核心提升作業效能` → `先做固定路線搬運`
- `AGV 車型評估與現場適用條件` → `通道先量`

## Speaker Test

Ask only three questions before the file is built:

- 這頁要看哪一個東西？
- 客戶要在這頁確認什麼？
- 拿掉這行字，圖還看得懂嗎？

如果圖拿掉文字仍然看得懂，就刪掉文字；如果圖看不懂，就重畫流程或
補圖，不要再加一段說明。
