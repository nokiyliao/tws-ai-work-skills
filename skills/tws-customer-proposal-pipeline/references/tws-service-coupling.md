# TWS Service Coupling

Use this to map target-customer signals to TWS proposal modules.

## Positioning

Position 奔騰物流 / TWS as a warehouse and intralogistics system integrator:

- Warehouse planning and rack/storage design.
- WMS / WCS and ERP/MES interfaces.
- Dense storage, Modula, shuttle systems, AGV/AMR, dock/staging, conveyor.
- Toyota Material Handling group brands, Modula, MBB, Galaxis, AiTEN, Geek+, rack systems, FastLINK, LionsBot.
- Implementation and service support.

Do not position TWS as only an equipment reseller.

## Signal-To-Service Map

| Customer signal | Proposal thesis | TWS modules |
| --- | --- | --- |
| ERP/MES rollout, dashboards, immediate reporting | Digital core exists; physical logistics must become system-readable | WMS/WCS, barcode, task dispatch, ERP/MES interface |
| New factory, green building, expansion | Decide logistics skeleton before construction locks constraints | layout, rack, dock/staging, power/charging, WMS/WCS, phased equipment |
| Old site / low ceiling / constrained site | First improve visibility and storage logic; avoid over-building | WMS/WCS, Modula, low-height dense storage, AGV/AMR, phased retrofit |
| High SKU / small parts / tools / spare parts | First contain picking, traceability, and storage accuracy | Modula, small-parts storage, WMS, barcode/RFID |
| Line-side supply / WIP / factory material flow | Convert work orders into logistics tasks | WMS/WCS, line-side staging, AGV/AMR, route planning |
| Export packing / shipping marks / EDI/customer requirements | Link outbound staging to order and packing status | WMS, dock/staging, labeling, conveyor, FastLINK/dock equipment |
| ESG, carbon footprint, energy management | Logistics data supports energy, paper, and movement reduction | route optimization, equipment telemetry, paperless WMS, cleaning robot |
| Labor shortage / safety / human-vehicle conflict | Reduce repeated movement and improve people-flow separation | AGV/AMR, dock planning, safety zones, route controls |

## Proposal Language

Prefer business outcomes:

- `讓 ERP / MES 看得見，讓現場跟得上。`
- `把訂單、工單、庫存與設備任務接成閉環。`
- `先資料化，再流程化，最後分期自動化。`
- `不一次推滿設備，用一條高頻流程驗證資料、任務與回寫。`

Avoid:

- Internal notes, draft labels, source-row language.
- Over-specific ROI claims without source data.
- Catalog pages that list models without linking them to customer pain.

## First-Meeting Outputs

The deck should end with a concrete next step:

- `30-60 分鐘導入評估會` for early cold outreach.
- `2 小時現場交流 + 1 次物流節點盤點會議` for stronger targets.

Meeting confirmation items:

- floor plan, ceiling height, columns, doors, charging areas.
- SKU, carton/bin/pallet sizes, weights, turnover.
- ERP/MES fields and interface boundaries.
- receiving, WIP, line-side, finished goods, outbound process.
- constraints: safety, power, fire, clean zones, expansion plan.
